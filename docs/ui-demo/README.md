# 动作生产工作台交互原型

直接用浏览器打开 [dist/index.html](dist/index.html)。单文件、不需要安装依赖，也不需要启动 ComfyUI、Blender 或 video2rig。

本原型面向亲自批量生产与调试动作的制作者。Sol / Astra 是未来实现工具的开发者，不是本界面的日常操作者。

## 可演示的流程

1. 在“视频候选”编辑动作说明、选择参考视频；不建议使用的候选不能提交拟合。说明的修改只影响下一次生成，并随任务记录保存。
2. 在“拟合调试”播放、逐帧查看、拖动时间轴、切换视角和骨架显示。
3. 修改平滑、脚锁定等参数并提交重算，在“运行队列”暂停、取消和重试。修改参数不会立即改变旧版本预览。
4. 完成后查看新版本，在“版本比较”同步对照两个拟合版本，然后明确采用一个正式版本。继续重算不会覆盖它。
5. 导出固定采用版本，到“交付库”下载带有动作、候选、参数与导出设置的 JSON 演示清单。
6. 使用“批量新建动作”一次创建多个动作并生成候选；左侧勾选支持批量生成和导出已采用动作。
7. 在“角色库”查看识别器状态、模拟训练或登记新的 Blender 文件名。

## 演示边界

- 模型、动作、候选检查值和任务进度均为程序化示意。未连接实际推理、视频生成、模型检查或 Blender 导出。
- 文件选择仅登记文件名，不读取模型或视频内容，不上传文件。
- 导出只产生 JSON 清单，不生成真实 FBX / GLB / BLEND。循环、采样率和根运动选项用于展示正式工具的导出决策。
- 页面通过浏览器 localStorage 保存模拟任务、参数和采用记录。“重置演示”仅清除本原型的状态。
- 预览用于解释交互；真正的三维模型、视频同步和动画编辑需要在正式实现中接入。

## 正式实现的职责边界

- 界面服务于人工制作：角色建档、批量动作清单、候选筛选、动作预览、参数试算、版本采用与成品导出。
- ComfyUI 执行已固定的视频生成工作流。video2rig 使用独立环境；Blender 承担角色准备、渲染、动作导入与导出。
- 本地任务层统一记录任务状态、输入版本、参数和产物，处理显存调度、取消、失败恢复与缓存有效性。界面不承担这些规则。
- 第一版将精细的骨骼、曲线和 IK 修改交给 Blender，并将人工修整结果登记为独立版本；不在网页中重做完整动画编辑器。
